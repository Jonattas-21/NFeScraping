# Overview
This app solve a problem of consulting NFes status in SP city hall using a scraping approach.

## The problem
Auditors need to consult many NFes status in a accountant report, they need to check if the NFe status described in the report matches with the SP city hall digital status. Therefore the app cames up with the function to read the accounting report, using OCR to identify a NFe and capture the data from the report and finaly look up in the São Paulo City Hall web site, creating a adtional report of NFe and Status per accounting report.

## How to run
1) intall Tesseract previously 
2) make build
